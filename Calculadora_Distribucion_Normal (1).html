4. Instrucciones para utilizar el programa

  1. Selecciona Normal si conoces la media (μ) y la desviación estándar (σ). Selecciona Binomial con Yates si el problema habla de un número de ensayos y una probabilidad de éxito.
  2. Elige el tipo de evento: izquierda, derecha, intervalo, exterior o exactamente un valor.
  3. Escribe los datos. Para la binomial, ingresa p como decimal: por ejemplo, 80 % = 0,80.
  4. En el modelo binomial, especifica si se incluyen los extremos. El programa corregirá automáticamente los límites en 0,5.
  5. Presiona Calcular y dibujar. Observa el área sombreada y lee cada paso hasta obtener el porcentaje.
  6. Presiona Generar ejercicio aleatorio para practicar con otros valores. Puedes imprimir el resultado.

Importante: la probabilidad calculada para una normal es exacta dentro de la precisión numérica. Cuando se usa la normal para aproximar una binomial, el resultado es una aproximación, no la probabilidad binomial exacta. La regla np ≥ 5 y n(1−p) ≥ 5 es orientativa.
